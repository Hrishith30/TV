Where do I find these?

From your IPTV provider you get 3 things: a Server URL / Host / Portal (e.g. http://line.example.com:8080), a Username and a Password. Paste them exactly. No playlist file needed.

If login fails with a network error, make sure the Server URL includes http:// or https:// and the correct port, or host this file on the same domain as your provider.
